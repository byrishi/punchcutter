# Pomelo Round

A soft, friendly rounded sans for packaging, apps for kids and anything that should smile.

- Weights: Regular (400), Bold (700) plus a variable font (wght axis)
- 277 characters: Basic Latin, Latin-1 and Latin Extended-A accents, punctuation, currency
- OpenType features: kerning, tabular figures (tnum), slashed zero (zero), case-sensitive forms (case), alternate a (ss01)

## Files

- `variable/` one file, every weight (best for the web)
- `ttf/`, `otf/` desktop fonts: install these
- `webfonts/` WOFF2 for websites
- `PomeloRound.css` ready-made @font-face rules
- `studio.html` the font's app: test it, inspect glyphs, download (works offline)

## Use on a website

```html
<link rel="stylesheet" href="PomeloRound.css">
<style>body { font-family: "Pomelo Round", sans-serif; }</style>
```
