# Burin Grotesk

A calm neo-grotesque for interfaces and editorial work. Closed apertures, flat terminals, a tall x-height.

- Weights: Light (300), Regular (400), Medium (500), Bold (700), ExtraBold (800) plus a variable font (wght axis)
- 277 characters: Basic Latin, Latin-1 and Latin Extended-A accents, punctuation, currency
- OpenType features: kerning, tabular figures (tnum), slashed zero (zero), alternate a (ss01), case-sensitive forms (case)

## Files

- `variable/` one file, every weight (best for the web)
- `ttf/`, `otf/` desktop fonts: install these
- `webfonts/` WOFF2 for websites
- `BurinGrotesk.css` ready-made @font-face rules
- `specimen.html` open in a browser to test the fonts

## Use on a website

```html
<link rel="stylesheet" href="BurinGrotesk.css">
<style>body { font-family: "Burin Grotesk", sans-serif; }</style>
```
