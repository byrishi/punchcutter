Use it

On your computer

  1. Download the family and unzip it.
  2. Open ttf (or otf) and double-click each file.
  3. Click Install. It appears in every app.

On a website

  1. Copy the webfonts folder and the CSS file to your site.
  2. Add the rules below, then set font-family.
